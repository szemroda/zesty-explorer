## Human-only final sanity check

Automated tests deliberately do not use a real Zesty cookie. A permitted user may perform one read-only check in current Chrome and Edge: start the app, supply their own deployment cookie, open one Content or Blocks collection, add one relationship, filter it, copy a link, inspect that the link has no token, and confirm in the Network panel that app requests target only the canonical Zesty API host. This check introduces no additional setup requirement and must never record the authorization header.
